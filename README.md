# LEGUMIO website prototype

Public static prototype for LEGUMIO, an AI-first snack concept featuring plant-powered chickpea, pea and lentil crisps.

## Important

This is a concept store. Checkout, payment, inventory, analytics and form submissions are simulated. Product claims, nutrition, allergen statements, pricing and availability require commercial validation before use.

## Local preview

```bash
python3 -m http.server 4173
```

Open http://localhost:4173.
